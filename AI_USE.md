# AI Use Disclosure

Generative AI was permitted for all coding in this assignment. I used ChatGPT
to help design the repository structure; draft, debug, and document Python
code; propose monetary-policy phrase lists and semantic anchor sentences; and
improve the clarity of the written methodology. I reviewed the generated code,
ran the analysis, inspected intermediate data and outputs, and remain
responsible for the methodological choices, factual claims, interpretation,
and final submission.

AI was not treated as a source of empirical results. All reported document
counts, tone estimates, market reactions, regressions, probabilities, and
figures were generated from the cited Federal Reserve, FRED, and Yahoo Finance
data by the code in this repository.
